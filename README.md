### What I learned

<!-- Use this section to recap over some of your major learnings while working through this project. Writing these out and providing code samples of areas you want to highlight is a great way to reinforce your own knowledge. -->
I have learned that while positioning elements, using position: relative rather than using position: absolute can help us while arranging the overall layout of the section in which we are working because, if we use position: absolute, the element leaves its position as well as space, and the element which was below the positioned element occupies that space. Even the margin property does not work on the absolutely positioned element. So, using position: relative, which does not cause the above stated problems, is a work-around.
